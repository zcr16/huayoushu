# 花有数 · HarmonyOS 工程

当前源码版本为 **2.3.3**。这是供开发者自行构建的工程，尚非应用商店发行版，不包含可通用于所有设备的签名安装包。

## 功能与边界

原生工程承载本地账本网页，并提供系统选图、截图、语音转文字、闪控球及人物互动。图片交给自行配置的云端千问整图识别；账单查重在本机进行。普通收入、支出可以先保存为“账户待归属”，不要求先创建资金账户，也不会修改实际银行卡或钱包余额。保存勾选交易后回到首页；转账、还款仍需明确双方账户。

点人物先展开菜单，只有点“截图记账”才执行截图。互动包含14种本地动作，支持保存2–6个常用动作；互动不截图、不联网。左上角系统按钮用于收起菜单，×用于关闭助手。

**当前截图后自动返回应用仍有平台限制。** 真机窗口恢复调用曾返回 `801` / `201`，不能保证截图后自动拉回主应用。遇到无法返回时，请手动打开花有数查看识别状态，或使用应用内选图入口。编译成功和模拟测试通过不等于这条真机链路已通过。

## 环境与构建

需要 Node.js 20+、DevEco Studio 和 HarmonyOS API 26 SDK。设备需要支持使用到的系统能力。

在项目根目录准备依赖及网页资源：

```sh
npm ci
npm run package:harmony
```

然后用 DevEco Studio 打开 `harmonyos/`，完成 SDK 配置并构建。网页打包脚本将 `web/` 页面、样式、脚本和图表资源内嵌到 `entry/src/main/resources/rawfile/index.html`；修改网页后应重新打包。

Windows 开发者也可使用 `scripts/build.ps1`，通过 `-DevEcoHome` 显式传入自己电脑上的 DevEco Studio 安装目录。不要使用其他开发者的本机路径。

## 签名和权限

应用包名为 `com.huayoushu.ledger`。使用自己的华为开发者账号，在 DevEco Studio 中为项目配置官方签名。需要改变包名时，同时核对 AppScope、原生返回应用逻辑及相关配置。

仓库不提供私钥、证书、设备专属 Provision Profile、签名密码或预先获批的受限权限。`USE_FLOAT_BALL` 等能力须通过华为官方流程申请并使用有效签名，不能通过修改 Profile 代替授权。闪控窗、截图与麦克风还需按实际系统要求完成运行时用户授权；未授权或设备不支持时，应使用应用提供的其他入口。

更新自己的安装版本时保留相同应用身份，并使用正常覆盖安装流程。卸载或清除应用数据可能删除本地账本，请提前导出 JSON 备份。

## 云端与数据

云网关需自行部署，见 [部署说明](../cloud/部署说明.md)。手机填写自己的 HTTPS 服务地址和应用连接码，不填写模型提供商 API Key。

本次压缩图片或记账文字会发送到配置的模型网关。完整账本留在本机，手机和电脑暂不自动同步。应用不监听付款事件，不自动读取第三方应用流水，也未接入小艺执行其他手机操作。

当前预算提醒发生在应用内，没有关闭应用后的后台预算推送。人物素材的许可范围见 [第三方归属](../THIRD_PARTY_NOTICES.md)。

## 验证

项目提供账本、网页交互及原生生命周期测试。原生测试需要本机 SDK 的 TypeScript 编译工具，具体工具路径以测试脚本的环境变量配置为准。权限首次申请、系统关闭与收起、截屏后的窗口恢复、语音服务可用性及实际保存结果应在目标设备另行验证；请使用合成测试数据。
