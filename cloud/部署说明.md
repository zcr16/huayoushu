# 自行部署花有数 AI 网关

网关基于 Node.js，接收单次记账文字或图片，返回待核对草稿。它不负责保存账本；账户与查重在客户端处理。仓库不包含可共享使用的服务地址、模型 Key 或连接码。

## 部署内容

运行时需要 Node.js 20 或更高版本。`server.cjs` 本身没有 npm 运行依赖。

PowerShell 打包：

```powershell
./cloud/build-package.ps1
```

脚本生成的 ZIP 只包含根层的 `server.cjs`，不会部署资源，也不会收集环境变量、证书或账本。也可将 `server.cjs` 单独部署到自己的 Node.js 服务环境。

将服务放在 HTTPS 入口之后，设置与平台一致的监听端口，并使用自己的域名和身份认证。使用函数计算时，按控制台当前提供的 Node.js / 自定义运行时配置启动命令；部署后的实际环境须支持代码所用的 Node.js API。仓库 `s.yaml` 只是函数资源示例，不是完整的一键生产部署配置，HTTP 触发器认证与域名须另外配置。

## 环境变量

| 名称 | 用途 / 示例 |
| --- | --- |
| `PORT` | 服务监听端口，例如 `9000`；应与托管平台配置一致 |
| `HYS_AI_PROVIDER` | 云端模式设为 `dashscope` |
| `DASHSCOPE_API_KEY` | 部署者自己的百炼 API Key，仅存服务器环境或密钥管理服务 |
| `HYS_AI_MODEL` | 文字模型，例如 `qwen-flash` |
| `HYS_VISION_MODEL` | 视觉模型，例如 `qwen3-vl-plus`；不配置时不启用图片识别 |
| `HYS_AI_TOKEN` | 独立随机应用连接令牌，16–256字节，不含空白；不是百炼 Key |
| `HYS_PUBLIC_HOSTS` | 允许的准确主机名，例如 `ledger.example.com`；多个以逗号分隔，不带协议、路径或通配符 |
| `HYS_AI_TIMEOUT_MS` | 上游请求超时，默认 `45000` 毫秒 |
| `HYS_AI_MAX_CONCURRENT` | 进程内模型请求并发上限，默认 `1` |
| `HYS_AI_REQUESTS_PER_MINUTE` | 进程内每分钟请求上限，默认 `6` |
| `HYS_AI_REQUESTS_PER_DAY` | 进程内每日请求上限，默认 `100` |
| `HYS_ALLOWED_ORIGINS` | 可选网页来源名单；跨域使用时填写自己的准确页面 origin |

`ledger.example.com` 仅为文档示例，不能作为可用服务地址。不要将真实值提交到仓库、贴入 Issue 或放进客户端代码。

当前网关代码固定使用百炼兼容接口 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`。Key、模型权限及模型可用地域应与该上游接口匹配；客户端服务地址不能用来覆盖上游模型地址。模型可用性、额度和费用以自己的服务账号为准，本仓库不承诺免费额度。

## 入口认证与手机配置

模型接口要求 `Authorization: Bearer <HYS_AI_TOKEN>`。在托管平台同时配置入口认证，例如函数计算的 Bearer HTTP 触发器；入口令牌须与应用连接令牌保持一致，并满足平台自己的格式限制。网关层的模型请求校验不应替代平台入口的访问控制。

客户端“设置 → AI 连接”选择云端模式，填写自己的 HTTPS 服务根地址和应用连接码。模型提供商 Key 始终留在服务器。需要网页跨域访问时，仅加入自己控制的页面 origin。

## 验证接口

- `GET /api/health`：检查配置，不调用模型。云端模式的 `configured:true` 只表示 Key 存在，不能证明真实模型调用成功；启用图片识别时还应有 `receiptVision:true`、`receiptProtocolVersion:1`。
- `POST /api/parse`：整理单次文字，返回 `draftProtocolVersion:2` 草稿。
- `POST /api/receipt`：识别单次压缩图片，返回 `receiptProtocolVersion:1` 的多笔草稿。

按托管入口要求携带认证。先用合成文字和合成账单图片验证；不必提交真实账本。AI 结果仍需在客户端确认后保存。

## 运行边界

云端模式只提供 API，不提供账本网页静态托管；网页版可单独运行本地开发服务后连接该网关。使用不同版本客户端时，应核对草稿协议与视觉接口版本。

请求上限按**单进程**统计，进程重启后会重置，多实例之间不会共享计数；它不是云账号的全局预算上限。托管平台还应按自己的成本需求设置实例、并发和模型额度。服务没有自动付费重试。

网关源代码不主动记录用户输入、模型响应或连接令牌，也不写入账本。上游模型服务和托管平台可能有各自的数据处理与日志配置；部署者需自行管理。公网入口使用 HTTPS，不要将开发服务的裸 HTTP 端口直接作为公共接口。
